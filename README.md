# Healthcare Management Web Application

A web application developed to support hospital management workflows and healthcare-related information.

## Overview

The objective of this project was to build a web platform capable of supporting different hospital management processes while maintaining a structured connection between frontend interfaces, backend services, and stored data.

The project was developed as part of an academic multidisciplinary project.

## My Contribution

- Developed frontend components using React
- Implemented backend services using ASP.NET and C#
- Designed relational database structures using SQL
- Connected frontend functionality with backend services
- Worked with healthcare-related data management
- Tested application flows and user interactions
- Identified and improved issues related to data handling and application behaviour
